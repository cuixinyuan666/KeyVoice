# KeyVoice · 按键语音

**Android 9 上按一个实体键 → 后台直接调用手机里的讯飞识别引擎做语音转文字（不弹输入法框）→ 送到 Windows 10 → 直接上屏到你正在用的输入框。**

- **后台识别**：默认走「识别服务模式」，直接调系统/讯飞的语音识别引擎，全程无界面、不弹输入法框。
- **任意输入框上屏**：Win10 收到文字后写剪贴板、还原你正在用的窗口焦点、`Ctrl+V` 上屏到任意有光标的输入框（记事本、浏览器、微信…）；没有光标就只存剪贴板并弹窗提示。
- **锁屏可用**：亮屏用实体键；**锁屏下**用通知栏「听写」按钮（锁屏可直接点）或耳机媒体键，触发后会点亮屏幕完成听写、停了自动灭屏。
- **局域网自动发现（多设备互发现）**：电脑打开接收端后在「等待连接」；手机点「搜索设备」会列出同一局域网内的**所有 KeyVoice 终端**（电脑和手机），点一台即可填好 IP 并连上，无需手动查 IP。后加入的设备也能正常被发现。
- **文件互传（v0.4.0）**：手机 ↔ 电脑互传**任意类型文件**。手机端点「文件」按钮选文件发送；电脑端点「发文件」推送到手机。双向流式传输、大文件不占内存，落盘到 `Download/KeyVoice`（手机）/ `Downloads\KeyVoice`（电脑），列表里点「打开」即用系统应用打开。
- **远程互控（v0.4.0）**：
  - **手机控电脑**：电脑端点「远控」→ 手机 App「远程控制」页打开即看到电脑屏幕并操作（触摸=鼠标、长按=右键、双指=滚轮、键盘按钮可输中文），零安装、PIN 保护。
  - **电脑控手机**：电脑端点「手机投屏」→ 一键调用 [scrcpy](https://github.com/Genymobile/scrcpy)（151k★）投屏+键鼠控制，手机端不用装任何东西。

```
[实体按键(亮屏) / 通知栏按钮(锁屏) / 耳机媒体键 / 快捷磁贴 / 广播]
        │
        ▼
手机端 App（后台调讯飞识别引擎，无界面）
        │  adb reverse 隧道（USB）或 局域网 WiFi
        ▼
Win10 状态小窗（右上角置顶）
        │
   有输入光标 → 还原焦点 + Ctrl+V 上屏；无光标 → 存剪贴板 + 弹窗提示

文件互传：手机「文件」页 ⇄ 电脑「发文件」（同一条 HTTP 通道，流式传输）
远程互控：手机「远程控制」页 ⇄ 电脑「远控」开关（MJPEG + SendInput，PIN 保护）
          电脑「手机投屏」→ 一键调起 scrcpy（电脑控手机）
```

## 和 GitHub 上已有方案的区别

现成项目（`mofanx/voice-input`、`QAA-Tools/qaa-airtype`、`franj/PhoneMic`、`signalband/Sinput`、`enximi/tele_type_phone`）思路都是：**手机上打开网页/App → 点按钮说话 → 发到电脑**。它们能用，但缺的正是本项目的重点：

| | 现有项目 | KeyVoice |
|---|---|---|
| 实体/自定义按键触发 | ❌ 要先摸屏幕点按钮 | ✅ 无障碍服务截获物理按键，也能绑耳机键、收广播 |
| 后台识别、不弹输入法框 | ❌ | ✅ 识别服务模式直接调引擎 |
| 锁屏操作 | ❌ 必须亮屏 | ✅ 通知栏按钮 / 媒体键触发，点亮屏幕完成听写 |
| 通道 | 全部走局域网 | ✅ **adb（USB）为主**，局域网可选 + 自动发现 |
| Win10 端 | 多为命令行 + 剪贴板 | ✅ 状态小窗：连接状态 / 最近收到 / 弹窗提示 / 直接上屏 |
| 用手机已装的讯飞 | ✅（输入法） | ✅ 识别服务模式优先复用讯飞引擎 |
| 文件互传 | 另一个 App（LocalSend 等） | ✅ 内嵌同一个 App：复用消息通道与自动发现，免装第二个应用 |
| 手机控电脑 | RustDesk 等独立两端安装 | ✅ 内嵌网页远控（noVNC 架构），打开即用、PIN 保护 |

**关于「不重复造车轮」——本项目对高 star 开源方案的取舍：**

| 需求 | 高 star 方案 | KeyVoice 的做法 |
|---|---|---|
| 文件互传 | [LocalSend](https://github.com/localsend/localsend)（93k★，Flutter 独立应用） | LocalSend 是 Flutter 独立应用、无法嵌入本项目（Java + Python）。**复用它验证过的协议形态**：单次 HTTP 请求直传、元数据走 query、流式落盘；通道直接复用 KeyVoice 已有的 adb/局域网双通道与 UDP 自动发现，手机和电脑都不用装第二个应用 |
| 电脑控手机 | [scrcpy](https://github.com/Genymobile/scrcpy)（151k★，ADB 通道） | **直接集成原版 scrcpy**：电脑端点「手机投屏」一键检测/启动，USB 或无线 adb 均可，手机端零安装 |
| 手机控电脑 | [RustDesk](https://github.com/rustdesk/rustdesk)（125k★）、[KDE Connect](https://github.com/KDE/kdeconnect-kde) | RustDesk 要两端各自安装（体验最佳但重）；KeyVoice 内置**网页远控**（架构参考 [noVNC](https://github.com/novnc/noVNC)/[Guacamole](https://guacamole.apache.org/)「浏览器即客户端」：电脑端出 MJPEG 流 + SendInput 注入，手机端 WebView 直开），零安装、即时可用；重度使用建议再装 RustDesk 互补 |

## 一、Windows 10 端

零依赖，Python 自带库（tkinter）就能跑（网页远控为可选功能，见第六节）。

```bat
cd pc
python keyvoice_box.py            :: 默认端口 17890
python keyvoice_box.py 9000       :: 换端口
```

> 也可以直接**双击 `pc\启动接收端.bat`**：它会优先用 pythonw 后台启动（无黑窗口）。

打开后是一个**置顶的消息窗口**（默认右上角，可拖动、可贴边自动收起）：

- **顶栏**：状态（监听中 / 已连接 · 收到 N 条）+ **手机投屏**、**远控**、**改名**、**搜索设备** 按钮
- **设备栏**：本机名称 + 局域网内发现的设备清单；点「搜索设备」重新扫描
- **消息列表**：收到的文字逐条一行（复制 / 编辑 / 拖到输入框粘贴）；收到的文件显示为「📄 文件名」行（**打开** / 定位**目录**）
- **底部**：
  - 第一行：**上屏** · **发到手机**（把输入框内容群发） · **发文件**（选文件推送手机） · **收件箱**（打开电脑收件目录）
  - 第二行：**清空输入框** · **清空列表** · **收到即上屏**（勾选框）

**收到文字时**：窗口绿闪 + 右侧小提示窗（2.5 秒自动消失，不抢焦点）。

**上屏原理**：接收端持续跟踪「你正在用的窗口」，收到文字 → 写剪贴板 → 用 `AttachThreadInput` 把焦点还给那个窗口 → `Ctrl+V` 上屏。所以文字进的是你光标所在的输入框，而不是接收端自己。

> 第一次运行若 Windows 防火墙弹窗，选「允许访问专用网络」。局域网模式需要放行入站 TCP 17890（文字/文件接收）、UDP 17891 与 17893（发现）、TCP 17894（远控）—— 可运行 `pc/allow_firewall.bat` 一键放行。

## 二、adb 通道（不用局域网，推荐）

手机插 USB，电脑上执行一次：

```bat
adb reverse tcp:17890 tcp:17890
```

这条命令把**手机自己的 `127.0.0.1:17890`** 映射到**电脑的 `17890`**。所以手机 App 发往 `127.0.0.1:17890`，就等于发到电脑，全程不经过 WiFi。App 里「传输方式」选 **adb（USB 线，不需要局域网）** 即可（默认就是这个）。

> 拔线或重启手机后 `adb reverse` 会失效，重新插线再执行一次。

其它触发/发送方式（都走同一条通道）：

```bat
adb shell am broadcast -a com.keyvoice.TRIGGER -n com.keyvoice/.TriggerReceiver
adb shell am broadcast -a com.keyvoice.SEND_TEXT --es text "直接发这句话" -n com.keyvoice/.TriggerReceiver
```

**adb 要不要 root？** **不需要。** 只要开「开发者选项 → USB 调试」。

## 三、局域网通道（无线，含自动发现）

适合不想插线、或想纯无线的场景。手机和电脑要在**同一个 WiFi**（或电脑连手机的**热点**，两者即同网段）。

1. 电脑上先跑 `python pc/keyvoice_box.py`，**首次用局域网先右键管理员运行 `pc/allow_firewall.bat`** 放行 17890/17891/17893
2. 手机 App 里「传输方式」选 **局域网 WiFi**
3. 点 **搜索设备** —— 手机会广播发现请求，局域网内的**电脑和手机**都会应答并列出名称；点一台电脑，**自动填好 IP、切成局域网模式并测试连接**，状态显示「已自动连接：xxx」。（多台会让你选）

**发现协议**（手机和电脑两端都会应答，所以后加入的设备也能被搜到）：

| 端口 | 请求 | 应答 | 应答方 |
|---|---|---|---|
| 17891（老协议） | `KEYVOICE_DISCOVER` | `KEYVOICE_HELLO:<端口>` | 仅电脑 |
| 17893（新协议） | `KV_DISCOVER` | `KV_PC_HERE:<端口>:<设备名>` | 电脑 |
| 17893（新协议） | `KV_DISCOVER` | `KV_PHONE_HERE:<端口>:<设备名>` | 手机 |

扫描端会同时向两个端口的子网定向广播地址 + `255.255.255.255` 发送请求，按 IP 去重后合并结果（同一台设备新老协议都回包时，取带名字的那条）。

### 设备名称与设备数量

每个终端（手机 App 和电脑接收端）都会显示**本机名称**和**局域网内发现的设备数量**：

- 手机：主页面顶部一行显示「本机名称 · 发现 N 台设备」，点一下可重新搜索并查看完整清单；设置页「设备」卡片里可改本机名称。
- 电脑：接收端窗口顶部的设备栏显示本机名称与「发现 N 台设备：xxx（手机 192.168.1.6）…」，右侧「搜索设备」重新扫描、「改名」修改本机名称（存 `%APPDATA%\KeyVoice\config.json`）。

设备名会随发现应答一起广播，所以其它终端列表里看到的是「张三的手机」而不是一串 IP。

### VPN 注意

手机开着 VPN 时，发往 `255.255.255.255` 的广播会被隧道劫走、电脑收不到。本 App 已改为**按 WiFi 网卡算子网定向广播**（如 `192.168.1.255`）绕开 VPN 路由，多数情况能直接搜到；如果仍搜不到，App 会提示「检测到 VPN」，此时：

- 临时关闭 VPN 再搜；或
- 在 VPN App 里把「KeyVoice」加入**绕行/分流名单**；或
- 直接用 adb 模式（USB，不经过网络，VPN 完全无影响）

## 四、Android 9 手机端

### 使用方式（v0.3.0 统一深色设计）

主页面与 Windows 接收端已统一为同一套深色设计系统（配色 / 圆角 / 间距 / 触摸目标一致）。打开 App，主页面是：

1. **输入框** —— 讯飞语音识别出的文字落在这里（也可手动输入）
2. **🎤 模拟长按空格（开始说话）** —— 点一下：聚焦输入框、等输入法弹出，然后在讯飞键盘**空格键位置模拟"按住不松"**，直接说话，时长不限；再点一下 = **松开**，讯飞出字后**自动发送到电脑**（文字晚到也会等出字即发）
3. **电脑上屏** —— 把输入框里的文字手动发送到电脑光标处
4. **右侧竖排小按钮**（v0.4.0 起为八枚，均可长按拖动/缩放）：设置、模拟长按、电脑上屏、清除输入框、暂停/恢复、消息框开关，以及新增的
   - **📄 文件（左侧列）** —— 打开「文件互传」页：选文件发到电脑、查看已收文件
   - **🖥 远程控制（左侧列）** —— 打开远控页：手机控电脑（见第六节）

其余配置（电脑地址/搜索、语音引擎、常驻服务、权限引导等）全部在 **「设置」** 页。

### 配置步骤

1. 电脑上先跑 `python pc/keyvoice_box.py`（局域网模式还需放行防火墙）
2. **设置页**：语音来源默认**输入法模式（讯飞）**；传输默认**局域网 WiFi**，没填过电脑 IP 会**自动扫描**并连接
3. **权限**：设置页点「一键开启所需权限」自动逐项跳转（麦克风 → 无障碍 → 电池优化）。**「模拟长按」手势必须开启无障碍服务**（手势注入用）
4. **物理按键触发与遮蔽模式已在 v0.2.0 移除**；灭屏/锁屏听写仍可用通知栏「听写」按钮或耳机媒体键（识别服务模式）
5. 识别服务模式下要点「授予麦克风权限」

### 锁屏怎么用（重要）

**物理按键触发已移除（v0.2.0）**。锁屏/灭屏听写用这两种方式触发，二者不受系统限制：

- **① 通知栏「听写 / 停止」按钮**：下拉通知栏点本服务的按钮即可，**锁屏界面也能直接点**。触发后屏幕会点亮（dim）完成听写，停止后自动灭屏。
- **② 耳机 / 蓝牙媒体的播放键**：在设置页勾选开启，灭屏可用。

一句话：**亮屏用主页面「模拟长按」，锁屏用通知按钮或耳机键。**

### 关于「讯飞」与灭屏录音

- **识别服务模式（默认）**：直接调手机里注册了 `android.speech.RecognitionService` 的引擎，App 自动列出并标「（讯飞）」。讯飞输入法 / 讯飞语音引擎多数会注册；列表里没有就装一个「讯飞语音引擎」，或亮屏走输入法模式。
- Android 9 后台拿不到麦克风，所以灭屏听写必须 `startForeground()` 常驻 + 持 `PARTIAL_WAKE_LOCK`（CPU 不睡）+ `WifiLock`（网络不断）。息屏时 `SpeechRecognizer` 会被系统停掉，因此触发后会用 `SCREEN_DIM_WAKE_LOCK` 点亮屏幕完成听写再灭屏——这是无 root 下最稳的「锁屏语音」实现。

## 五、文件互传（手机 ↔ 电脑，任意类型文件）

复用消息的同一条 HTTP 通道与自动发现，**不用装第二个 App**。

### 手机 → 电脑

1. 电脑端接收端保持运行（端口 17890）
2. 手机主页面点 **「文件」** 按钮 → **「选择文件发送（可多选）」** → 选任意类型文件（不限图片/视频/文档，`*/*`）
3. 文件流式上传（大文件不占内存，进度条显示百分比），电脑端：
   - 消息列表出现一行「📄 文件名 + 大小」，点 **「打开」** 直接打开、**「目录」** 定位到资源管理器
   - 落盘目录：`%USERPROFILE%\Downloads\KeyVoice\`（同名自动加序号，不覆盖）
   - 可点底部 **「收件箱」** 一键打开目录

### 电脑 → 手机

1. 电脑端点底部 **「发文件」** → 选文件（可多选）
2. 自动发送到**局域网发现 / adb 连接的所有手机**（USB 模式会自动 `adb forward`，无需手动操作）
3. 手机端：文件存入 `Download/KeyVoice/`（Android 10+ 走 MediaStore 无需权限；Android 9 首次会请求存储权限，拒绝则自动退回 App 私有目录）
   - 主页面聊天面板出现一行「📄 文件名」消息，点 **「打开」** 直接用系统应用查看
   - 「文件」页可看到最近收到文件列表

### 协议（与 LocalSend 的「单请求直传」同形态）

```
POST /file?name=<URL编码文件名>&from=<设备名>   body = 文件原始字节
· Content-Length 固定长度（已知大小）或 Transfer-Encoding: chunked（未知大小），两端都支持
· 返回 {"ok":true,"saved":"下载/KeyVoice/x.zip","size":123456}
· 文件名在接收端做安全清洗（去路径分隔、非法字符，防目录穿越）
```

## 六、远程互控

### 6.1 手机控电脑（内置网页远控，零安装）

**电脑端**：点顶部 **「远控」** →（首次会提示安装 Pillow，可一键自动装）→ 弹出小窗显示：

```
地址： http://<电脑IP>:17894/remote
PIN：  8312   （手机首次输入一次后记住）
```

**手机端**：主页面点 **「远程控制」** 按钮 → 输入 PIN → 连接。即可：

| 手势 | 动作 |
|---|---|
| 单击 | 左键点击 |
| 长按（>0.55s） | 右键（也可先点顶部「右键」按钮，下一次点击为右键） |
| 拖动 | 按住拖动（选文字、拖窗口） |
| 双指上下滑 | 滚轮 |
| 顶部「键盘」→ 底部键盘条 | Esc/Tab/Enter/方向键/Ctrl+C 等；点输入区可调软键盘输中文 |
| 顶部「画质」 | 流畅(960)/标准(1280)/高清(1600) 三档，按网速自选 |

实现与安全：

- 电脑端 **kv_remote.py**：GDI 截屏 → Pillow 缩放 + JPEG → **MJPEG 流**（`multipart/x-mixed-replace`，Chromium/WebView 原生支持）；输入走 Windows `SendInput`（与 scrcpy 电脑侧同款注入方式）；**没有观看者时完全不做截屏**，看电影打游戏时开着也不拖慢电脑。
- 架构参考 **[noVNC](https://github.com/novnc/noVNC) / Apache Guacamole** 的「浏览器即客户端」：手机侧不需要任何额外 App。
- **PIN 保护**：全部数据接口校验 PIN，连续错 5 次锁定该 IP 10 分钟；远控默认关闭，用完即关。
- 必须先在电脑防火墙放行 **TCP 17894**（运行一次 `pc\allow_firewall.bat` 即可，已包含）。
- **adb（USB）模式**：先在电脑执行一次
  ```bat
  adb reverse tcp:17894 tcp:17894
  ```
  手机端会自动改连 `127.0.0.1:17894`，全程不经过 WiFi。

> 想要更流畅的体验（低延迟、声音、剪贴板同步）可另装 [RustDesk](https://github.com/rustdesk/rustdesk)（125k★，开源免费，局域网 IP 直连可用）——两者互补：KeyVoice 内嵌远控胜在零安装即时可用，RustDesk 胜在重度使用时的流畅度。

### 6.2 电脑控手机（集成 scrcpy，手机零安装）

**电脑端**：点顶部 **「手机投屏」**：

- 直接复用原版 [**scrcpy**](https://github.com/Genymobile/scrcpy)（151k★，ADB 通道，延迟 35~70ms，电脑鼠标键盘直接操控手机，不用在手机装任何东西）
- 首次使用：点按钮后按提示**双击 `pc\下载scrcpy.bat`** 自动下载安装到 `pc\tools\scrcpy\`（也可去 [Releases](https://github.com/Genymobile/scrcpy/releases/latest) 手动下 win64 包解压进去，或把目录加进 PATH）
- USB：连上手机、开启「USB 调试」→ 点按钮直接投屏
- 无线：先用 USB 执行一次 `adb tcpip 5555`，拔线后 `adb connect <手机IP>:5555`，之后电脑上随时投屏

**锁屏也能操作（重点）**：

| 场景 | 效果 |
|---|---|
| 手机黑屏时点「手机投屏」 | 投屏前自动先唤醒手机 → 窗口里看到的是**锁屏/桌面界面（不是一片黑）** |
| 投屏中手机又熄屏 | 在投屏窗口**右键点一下** = 熄屏时先唤醒 / 亮着时相当于返回键 |
| 在投屏窗口里解锁 | 鼠标拖动=滑动、键盘直接输锁屏密码，和操作真机完全一致 |
| 常用组合键 | `Alt+P` 电源（开关屏）· `Alt+O` 关屏但继续投屏 · `Alt+Shift+O` 开屏 |

- 投屏期间自动加了 `--stay-awake`：手机**插着充电线**时不会自动锁屏/息屏（长时间操作不断线）；没插电时系统仍可能按息屏时间锁屏，届时右键唤醒即可
- 实现说明：唤醒用 `adb shell input keyevent 224`（KEYCODE_WAKEUP，亮屏时是无操作）。scrcpy 文档说启动默认会 power-on，但实测 Flyme（Android 15）Dozing 状态下不生效、窗口会全黑，所以显式先唤醒
- scrcpy 通过 `ADB` 环境变量指定用「手机当前连接的那个 adb」（PATH/Android SDK 优先）：若改用 scrcpy 自带 adb（版本通常不同）会重启 adb server，导致正在生效的无线调试连接掉线

> 手机端「远程控制」页顶部也会提示这套流程；被投屏时手机上无任何弹窗。

## 七、编译与签名

```bat
gradlew assembleDebug      :: 调试包 app\build\outputs\apk\debug\app-debug.apk
gradlew assembleRelease
```

**正式签名**：把你的 `.jks` 放到项目根目录，复制 `keystore.properties.example` 为 `keystore.properties` 并填四行，然后 `gradlew assembleRelease`，产出即用你正式签名签好的 `app-release.apk`。没有 `keystore.properties` 时**不会**偷偷用测试签名，产出的是 `app-release-unsigned.apk`。签名文件与密码都在 `.gitignore` 里。

## 八、通信协议

手机 → 电脑：`POST http://127.0.0.1:<端口>/text`（adb 模式）或 `http://<电脑IP>:<端口>/text`（局域网模式）

```json
{ "text": "识别出的文字", "action": "paste", "ts": 1730000000000 }
```

- `action`: `paste` = 收到即上屏（默认）；`copy` = 只存剪贴板不上屏
- `from`: 发送方设备名（电脑端消息列表里显示来源，可选）
- 返回 `{"ok": true}`
- `GET http://<host>:<端口>/ping` 用于自动发现后的连通性探测

文件互传（双向同形态，端口与文字相同）：

```
POST /file?name=<URL编码文件名>&from=<设备名>      body = 文件原始字节
Content-Length 或 Transfer-Encoding: chunked 均可；返回 {"ok":true,"saved":"…","size":123}
```

网页远控（手机控电脑，端口 17894，需 PIN）：

```
GET  /remote               远控页面（HTML，手机 WebView 直接打开）
GET  /remote/stream?pin=…  MJPEG 画面流（multipart/x-mixed-replace）
POST /remote/input?pin=…   输入事件 JSON：
     {"t":"m","x":0.5,"y":0.5}       鼠标移动（归一化坐标）
     {"t":"d"|"u","b":"left"}        按下 / 抬起（left/right/middle）
     {"t":"c","b":"left","n":1}      点击（n=2 双击）
     {"t":"s","n":-1}                滚轮（±1 格）
     {"t":"k","ch":"你"}             字符（Unicode 注入，支持中文）
     {"t":"vk","v":"enter","mods":["ctrl"]}   特殊键 / 组合键
```

局域网自动发现见上文「局域网通道」一节：手机与电脑都会应答 UDP 17893 的 `KV_DISCOVER`，并各自回 `KV_PC_HERE:<端口>:<设备名>` / `KV_PHONE_HERE:<端口>:<设备名>`（17891 的 `KEYVOICE_DISCOVER` 仅用于兼容老电脑端）。

## 九、常见问题

**悬浮窗没反应 / 手机发不出**
- 电脑端程序是否运行；adb 模式是否执行过 `adb reverse`（`adb reverse --list` 可查）
- `adb devices` 能否看到手机；局域网模式确认同一 WiFi + 防火墙放行

**锁屏按物理键没反应（正常现象）**
- 系统不在锁屏下派发无障碍按键，请改用**通知栏「听写」按钮**或**耳机媒体键**（见第四节）

**识别服务列表里没有讯飞**
- 装「讯飞语音引擎」，或亮屏用输入法模式

**上屏到错误位置**
- 接收端已改为先还原你正在用的窗口焦点再 `Ctrl+V`；发之前确保光标在你想要的输入框。若仍错位，先点一下目标输入框再触发

**终端 / vim / ssh 里粘不上**
- 这些程序不接受 `Ctrl+V`，需要改成逐字 `SendInput(KEYEVENTF_UNICODE)`（可后续增加）

**手机发文件失败 / 电脑收不到**
- 与文字消息同通道，先按上面「悬浮窗没反应」排查（接收端是否运行、adb reverse、防火墙）
- 局域网模式需放行 TCP 17890（`allow_firewall.bat` 已包含）

**电脑「发文件」说没发现手机**
- 需要手机在局域网内被搜到（点一下电脑端「搜索设备」），或手机插着 USB 且 `adb devices` 能看到
- 手机端 App 需在运行（LanServer 监听 17892）

**手机点「文件」想保存到公共 Download，但文件跑到了 Android/data 里**
- Android 9 上首次会弹存储权限请求，点「允许」即可写公共 `Download/KeyVoice`；拒绝的话文件仍会安全收到（App 私有目录），只是位置较深

**「远控」按钮提示安装 Pillow / 安装失败**
- 远控的画面压缩需要 `Pillow`。点「是」会自动 `pip install --user pillow`（约 3 MB）
- 自动装失败时手动执行即可：`pip install pillow`（或 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pillow`）
- 纯文件互传 / 语音功能不需要 Pillow，装不装都不影响

**手机远控页打不开画面（一直"连接失败/黑屏"）**
- 电脑端要先点「远控」按钮（默认关闭），并确认防火墙放行 TCP 17894
- 核对 PIN 是否与电脑端远控窗口显示的一致（连续错 5 次会锁定 10 分钟）
- adb 模式需要先执行 `adb reverse tcp:17894 tcp:17894`
- 页面底部「画质」可切「流畅」降低带宽，卡顿时优先试这个

**「手机投屏」提示未找到 scrcpy**
- 去 https://github.com/Genymobile/scrcpy/releases/latest 下载 win64 包，解压到 `pc\tools\scrcpy\`（或加入 PATH），重开接收端即可
- 提示未检测到手机：USB 需开「USB 调试」；无线先 `adb tcpip 5555` 再 `adb connect <手机IP>:5555`
